# Automated Vision Screenshots

This directory stores automated visual captures generated by `vision/capture.mjs`.

## Agent-Friendly Naming Convention
Captures strictly follow the target-and-versioning taxonomy:

- **Versioned Iteration:** `<target_name>_v<N>.png`
  - Example: `hud_v1.png`, `hud_v2.png`, `hud_v3.png`
  - Preserves iteration history so agents can verify progress across refactor loops.
  - Automatically auto-increments if `--version` is omitted.
- **Latest Mirror:** `<target_name>_latest.png`
  - Example: `hud_latest.png`
  - Always mirrors the newest capture for instant diffing against `vision/reference/<target_name>.png`.

## Triggering Captures
```bash
# Capture next version for target 'hud'
node vision/capture.mjs --target hud

# Explicit version capture
node vision/capture.mjs --target hud --version 2
```
